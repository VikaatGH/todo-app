# To-Do App
A simple and user-friendly todo list application built with JavaScript, HTML, and CSS. The interface is inspired by the Pomodoro time management technique.

## Features  
- Personalized Greeting: The app stores the user's name in local storage and greets them on every visit.
- Date Display and Calendar: Displays the current date and integrates an interactive calendar using Pikaday.
- Task Management:
  Add, edit, delete, and mark tasks as done.
  Tasks are categorized (e.g., studying, working, hobbies) and sorted by time.
  Completed tasks are moved to the bottom of the list. 
- Local Storage Support:
  Stores user data (name) and tasks based on the selected date, so your plans are saved even if you refresh or close the app.

## Technologies Used  
- Core Technologies: HTML, CSS, and JavaScript.
- Libraries and Tools:
  [Pikaday](https://github.com/Pikaday/Pikaday) for calendar functionality.  
  [jQuery Clock Timepicker](https://github.com/loebi-ch/jquery-clock-timepicker) for time selection.  
- Design Elements:
  Icons from [Flaticon](https://www.flaticon.com/search? author_id=3268&style_id=1374&type=standard&word=tomato).  
- Fonts Fredoka, Finger Paint from [Google Fonts](https://fonts.google.com/).

## Usage  
- Open the app and enter your name for a personalized experience.  
- Use the calendar to select a date and manage tasks.  
- Add tasks with specific times and categories.  
- View and manage tasks in the list.  
- Mark completed tasks, which will automatically move to the bottom.
